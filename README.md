# TWIN TURBO · 双人分屏赛车

一个独立的本地赛车游戏项目。两个人共用一块键盘，左右各占半屏，中间固定分界线，各自的镜头跟随自己的赛车。

## 在线试玩

[打开 TWIN TURBO](https://twin-turbo-yiiiiming.heym0701.chatgpt.site)

已部署为网页，可直接使用电脑键盘游玩。当前访问权限为仅站点所有者。

## 直接玩

双击 **Twin Turbo.html**，用桌面浏览器打开即可。所有画面、逻辑和音效都在文件中，不需要安装依赖、连接网络或注册账号。

选择 3 圈或 5 圈，点击“开始比赛”。沿赛道顺时针行驶，先完成规定圈数获胜。

| 操作 | 玩家一：青色闪电 | 玩家二：橙色风暴 |
|---|---|---|
| 加速 | W | ↑ |
| 刹车 / 倒车 | S | ↓ |
| 左右转向 | A / D | ← / → |
| 氮气 | 左 Shift | Enter |
| 返回赛道，罚停 2 秒 | Q | / |

Esc 暂停 / 继续。空格可从发车区出发，也可暂停 / 继续。页面失去焦点会自动暂停。声音默认关闭，可在右上角开启。

氮气自动恢复；草地会明显减速。每一圈必须按顺序经过检查点，逆行、抄近路无法获得完整圈数。小地图同时显示两辆车，自己的标记有白色外圈。

## 开发

无需 npm 安装。项目使用原生 JavaScript、Canvas 2D 和 Web Audio。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765`。修改后刷新浏览器。

重新生成可离线打开的单文件版本：

```sh
python3 build.py
```

这个命令也会生成网页部署文件 `dist/index.html`。网站托管配置保存在 `.openai/hosting.json`。

运行自动化测试（需要 Node.js）：

```sh
node --test tests/*.test.mjs
```

## 结构

- `engine.js`：独立于界面的车辆物理、碰撞、计圈、罚停和比赛状态。
- `main.js`：双镜头渲染、赛道绘制、粒子、键盘控制、界面及合成音效。
- `index.html` / `style.css`：中文界面、双人操作说明及响应式布局。
- `tests/`：驾驶与界面事件的自动化回归验证。
- `build.py`：把源码打包成单个可离线运行的 HTML 文件。

推荐使用有实体键盘的桌面浏览器。某些普通键盘的多键防冲突能力有限，可能无法识别两位玩家同时按下的全部按键。移动端可浏览界面，但此版本需要键盘操作。
